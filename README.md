## What is HEADROOM?

HEADROOM is a VS Code extension I'm building to bring more structure to AI-assisted software development.

Instead of treating AI as a simple code generator, HEADROOM is designed around the work that happens around the code too — planning, objectives, tasks, execution, verification, and keeping track of what actually happened.

The goal is simple:

> **Give AI-assisted development more structure, visibility, and accountability.**

## What it does

HEADROOM is being built around a workflow like:

```text
Objective
    ↓
Plan
    ↓
Tasks
    ↓
AI-assisted Work
    ↓
Verification
    ↓
Result
```

This gives development work a clearer path from an idea to a verified result.

### Current capabilities

* Objective management
* Project and organization views
* Task and work tracking
* Execution-state management
* Local persistent storage
* AI provider configuration
* Secure credential storage through VS Code
* Development and verification workflows
* Extension-host testing infrastructure

The project is still evolving, and some larger AI-assisted workflows are under active development.

## Why HEADROOM?

AI can write code quickly, but software development is more than writing code.

Real projects also require:

* deciding what needs to be built
* breaking work into manageable tasks
* understanding project context
* checking whether changes actually work
* handling failures
* reviewing implementation decisions
* keeping track of progress
* knowing what was changed and why

HEADROOM is being built around those problems.

## Built for real development

HEADROOM is intended to work alongside the developer rather than replace the developer.

The direction is:

```text
Developer
    │
    ▼
HEADROOM
    │
    ├── Plan
    ├── Organize
    ├── Execute
    ├── Verify
    └── Review
          │
          ▼
       Developer
```

The developer remains in control.

## Example workflow

A development objective might look like:

```text
Objective
└── Add inventory system
    │
    ├── Design inventory data model
    ├── Implement inventory logic
    ├── Connect UI
    ├── Add persistence
    └── Test inventory behaviour
```

Each piece of work can be tracked and verified instead of disappearing into a long AI conversation.

## Development status

HEADROOM is **early-stage and actively under development**.

The foundation is being built incrementally, with an emphasis on:

* reliability
* security
* maintainability
* verification
* clear project state
* practical developer workflows

This repository represents an active development project rather than a finished product.

## Project direction

The long-term goal is to make HEADROOM a serious development environment for structured AI-assisted engineering.

That includes better planning, orchestration, project understanding, verification, debugging, and developer control — while keeping the system practical and understandable.
