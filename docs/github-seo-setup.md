## 3. Social Preview (Open Graph Card)

GitHub displays an Open Graph image when the repository link is shared across Discord, Slack, X/Twitter, and LinkedIn.

* **Asset**: `assets/headroom-banner.png` (Dimensions: 1200 × 380, dark technical aesthetic).
* **Manual Setup in GitHub Settings**:
  1. Navigate to **Settings > General > Social preview**.
  2. Click **Edit > Upload an image**.
  3. Select `assets/headroom-banner.png` from the local workspace.
  4. Save changes.
