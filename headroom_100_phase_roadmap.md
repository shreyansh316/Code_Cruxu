# HEADROOM — Reconstructed 100-Phase Foundation Roadmap

## Status and evidence

This roadmap was reconstructed on 2026-10-03 because no prior roadmap file or Phase 003 record was present in the repository, supplied attachments, or reachable Git history. It is an engineering plan inferred from the Phase 001 and Phase 002 commits, the current source and tests, the architecture notes, package choices, and the former Prisma schema removed in Phase 002. It is not a recovered verbatim copy of the lost roadmap. Future phases are plans, not completed work.

Evidence anchors:

- `9047b98 phase-001: initialize headroom vscode extension foundation`: established the VS Code extension, TypeScript/build/test infrastructure, core identifiers, hierarchy constants, and initial tests; removed Next.js app files but accidentally left the generated README text.
- `d60c8f0 phase-001: add .gitattributes for LF line ending normalization`: normalized tracked text line endings.
- `9d2210e phase-002: establish architecture and sqlite foundation`: removed Prisma, added layer boundaries and a real `better-sqlite3` compatibility check, and raised the Node engine requirement to 22.
- `src/storage/index.ts` says storage implementation starts at Phase 006; `src/domain/index.ts` says domain implementation starts at Phase 008; `src/infrastructure/index.ts` starts at Phase 021; `src/application/index.ts` starts at Phase 031; `src/agents/index.ts` starts at Phase 043.
- `src/constants.ts`, Phase 001 tests, extension commands, and the removed Phase 001 Prisma schema record the intended hierarchy, task states, offices, memory scopes, and core entities.

The Phase 003 choice is an inference, not a historical fact: define the canonical SQLite relational data model from the removed Prisma model and current constants, while leaving connection ownership, migrations, repositories, domain behavior, and agent behavior to their later architecture phases. The model tests provide deterministic evidence that the schema works. This follows Phase 002's explicit SQLite choice and precedes the storage implementation boundary documented as Phase 006.
